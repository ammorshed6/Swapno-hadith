# স্বপ্ন সংক্রান্ত হাদীস (Swapno Hadith)

সহীহ বুখারী (কিতাব ৯১) ও সহীহ মুসলিম (কিতাব ৪২) এর স্বপ্ন-অধ্যায়ের অফলাইন অ্যাপ।

## APK বানানো
1. সব ফাইল GitHub রিপোজিটরিতে আপলোড করুন (ফোল্ডার কাঠামোসহ)।
2. Actions ট্যাবে "Build APK" চলবে। শেষ হলে Releases > "Latest APK" থেকে SwapnoHadith.apk নামান।

## শুধু ডিজাইন/টেক্সট বদলাতে
`app/src/main/assets/index.html` ফাইলটি বদলে আপলোড করুন।
